# SymsvelModuleRoles

Documentation développeur.

## Intégration BO

Le scope BO fournit `bo/src/lib/modules/roles/index.ts`, avec l'identifiant `roles`, conformément aux modules natifs Admins et ACLs. Le synchroniseur Tooling reproduit ce chemin tel quel dans `bo/src/lib/modules/roles/`, sans renommer les dossiers. Aucune route SvelteKit n'est déclarée par ce module.
